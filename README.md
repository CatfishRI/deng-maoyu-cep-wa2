# deng-maoyu-cep-wa2
deng maoyu cep wa2

This is a simulation of charged particles with the gravitational and electromagnetic forces acting on them.
Controls: 

C: clear screen of particles 

Mouse click: adds particle 

Mouse drag: changes the user force field 

-: toggles all particles added after to a negatively charged one 

+: toggles all particles added after to a positively charged one 

M: toggles between normal mode and jiggle mode (larger electric force, creates very cool stable patterns) 

R: restarts simulation with the same seed 

N: restarts simulation with new seed 

T: toggles trail on or off 

E: splits all particles into 2 (provided original size or mass is above a fixed threshold)
